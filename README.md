# PolyArb — сканер вилок Polymarket ↔ букмекеры

Статическое веб-приложение (работает на GitHub Pages, без сервера): тянет цены Polymarket и коэффициенты букмекеров, сопоставляет матчи и ищет вилки.

## Возможности

### Киберспорт (Polymarket ↔ OddsPapi)
- CS2, Dota 2, LoL, Valorant, Call of Duty, Rainbow Six, Honor of Kings, Mobile Legends.
- Рынки: победитель матча (П1/П2), победитель карты, форы по картам (Ф1/Ф2), тотал карт (ТБ/ТМ), форы и тоталы раундов на карте.
- Букмекеры — через [OddsPapi](https://oddspapi.io) (v4, ключ в поле «Ключ OddsPapi»). Один скан тратит 1 запрос на список матчей дисциплины и 1 запрос на каждый сопоставленный матч (лимит — «Матчей за скан»). Справочник рынков кэшируется на сутки.
- Лимиты ставок букмекеров из OddsPapi учитываются в «Лимите».

### Валуйки и коридоры
- **Валуйки:** с линии «острого» бука (по умолчанию Pinnacle) снимается маржа → справедливая вероятность p. Ставка с ценой q (Polymarket с комиссией или 1/кэф) имеет EV = p / q − 1. Сумма — доля Келли от банка (по умолчанию ¼).
- **Коридоры:** пары линий вида Ф1(+2.5) + Ф2(−1.5) или ТБ(21.5) + ТМ(23.5), в т.ч. на картах и раундах. Ставки подбираются так, чтобы при выигрыше одной результат был одинаковым; показывается минус в этом случае и плюс, если зайдут обе. Целые линии (с возвратом) пропускаются.
- Для классического спорта валуйки считаются по исходу матча (Pinnacle есть в регионе `eu` у The Odds API).

### Общее
- Комиссия Polymarket берётся из рынка автоматически (`feeSchedule`: для спорта 0.05 × p × (1−p) от суммы).
- Фильтры: профит, кэф от/до, ликвидность, поиск, сортировка по профиту/времени, скрытие событий, «найдена N мин назад».
- Калькулятор: правка кэфов и ставок, округление ставок у буков, итог в $ и ₽.
- Журнал ставок: статусы, P/L по дням и букмекерам, экспорт CSV (хранится в браузере).
- Светлая и тёмная тема.
- Фильтр «Кэф не старше, мин»: пропускает коэффициенты букмекера, которые давно не обновлялись; у каждой ноги видно, когда кэф менялся.
- Кнопка «Диагностика» у OddsPapi: короткий отчёт о формате ответов (без ключа) — чтобы сверить парсер с реальными данными.
- Приложение на телефон (PWA): «На экран Домой», работает офлайн с последней версией, уведомления о вилках на устройство. На iPhone уведомления — только из установленного приложения; когда оно закрыто, надёжнее Telegram.

### Классический спорт (Polymarket ↔ The Odds API)

- **Polymarket**: события через Gamma API (`gamma-api.polymarket.com`), уточнение цены и ликвидности по стакану CLOB (`clob.polymarket.com/books`).
- **Букмекеры**: [The Odds API](https://the-odds-api.com) — 40+ контор (Pinnacle, Betfair Exchange, Marathon, 1xBet, William Hill, Unibet…). Бесплатный ключ даёт 500 запросов в месяц; один скан = 1 запрос на вид спорта и регион.
- **Матчинг**: нормализация названий команд, алиасы (Man Utd → Manchester United), сравнение токенов и биграмм, окно по времени начала.
- **Вилки**: 2-исходные (NBA/NFL/NHL/MLB/UFC) и 1X2 (футбол), включая NO-позиции Polymarket («не победа»). Перебираются все разбиения исходов; в каждой вилке обязательно есть и Polymarket, и бук (по желанию можно включить бук ↔ бук).
- **Комиссии**: taker-комиссия Polymarket и комиссия бирж (Betfair, Matchbook, Smarkets) учитываются.
- **Лимит**: сколько можно поставить, пока вилка держится, — считается по реальному стакану.
- **Калькулятор ставок**: суммы на каждую ногу, число акций на Polymarket, выплата.
- **Уведомления**: Telegram-бот, браузерные уведомления, звук; автообновление.
- **Демо-режим** — работает без ключей.

## Запуск

```bash
npm start          # http://localhost:8080
npm test           # юнит-тесты (node --test)
```

Или просто включить GitHub Pages для ветки — `index.html` лежит в корне.

1. Получите ключ на the-odds-api.com и вставьте его в поле «Ключ The Odds API».
2. Отметьте виды спорта и нажмите «Сканировать».
3. Для Telegram: создайте бота у @BotFather, напишите ему, возьмите chat id (например, у @userinfobot).

Ключи хранятся только в localStorage вашего браузера.

## Как считается

Стоимость $1 выплаты: Polymarket — `ask × (1 + комиссия)`, бук — `1 / коэффициент`
(биржа — `1 / (1 + (k − 1)(1 − комиссия))`). Вилка — набор ставок, покрывающих все исходы,
где сумма стоимостей < 1. Профит = `1 / сумма − 1`. Ставка на ногу = `банк × стоимость / сумма`.

## Ограничения и риски

- Если браузер блокирует запрос (CORS), укажите CORS-прокси в «Дополнительно».
- Теги видов спорта на Polymarket могут меняться — список правится в «Дополнительно → Свой список» (JSON).
- Перед ставкой проверяйте правила расчёта (овертайм, перенос/отмена матча), они у Polymarket и букмекеров могут отличаться.
- Коэффициенты Odds API обновляются с задержкой; буки режут лимиты «вилочникам».
